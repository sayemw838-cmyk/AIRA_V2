# AIRA V2.3.1

- **Homepage:** `index.html` — the current AIRA assistant interface, designed for mobile and desktop.
- **Task/model app:** `task-app.html` — the preserved agentic app, including model selection and `/tasks` features.
- **Compatibility URL:** `aira-interface.html` redirects to the homepage.

The assistant interface is a standalone frontend. To use live model responses, configure a trusted same-origin `/api/chat` backend; keep provider keys on the server, not in browser code.
